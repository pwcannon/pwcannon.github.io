# Website Redesign Context

This is Patrick Cannon's personal academic website. Jekyll + GitHub Pages.

## Design Direction
Tasteful retro (Win95-inspired palette and monospace headings, not pixel art).
Content-first. Must render LaTeX beautifully.

## See Also
- website_redesign_working_doc.md (in this repo) for full progress tracker
- Broader context: this website supports a job search targeting frontier AI
  labs (OpenAI, Anthropic, GDM, Meta FAIR, xAI). The site needs to read as
  "serious researcher with personality," not "hobbyist" or "novelty."

## Commands
- Deploy: push to master, GitHub Pages builds automatically
- Local preview: bundle exec jekyll serve
